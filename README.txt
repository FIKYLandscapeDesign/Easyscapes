easyscapes website - complete package

HOW TO DEPLOY (GitHub):
1. Upload the 7 .html files to your repo ROOT (overwrite existing).
2. Upload EVERY image from the "images" folder to your repo ROOT as well
   (GitHub flattens them - they must sit next to the .html files, NOT in a folder).
3. Commit. Netlify redeploys automatically.
4. Hard refresh the site (Ctrl+Shift+R / Cmd+Shift+R).

FILES:
- 7 HTML pages: index, styles, how, faq, about, contact, terms
- 6 hero images:        <style>-hero.png
- 6 style boards:       styleboard-<style>.png   (plant names blurred)
- 6 plant plans:        plant-plan-<style>.png   (cropped, no names)
- 6 package flat lays:  mockup-<style>.png
- about-home.png        (home page about section)
- testimonial-john.png  (John's review photo)

NOTE: images live in the "images" folder here only for tidiness.
On GitHub they must go in the repo ROOT, same place as the .html files.
